# Year 8 Agriculture - student evidence and assessment input pack

Status: reviewable TASK 11 integration input only. No formal assessment status is claimed.

## Student evidence promise

Every module must leave a student with answerable, saved and printable evidence. A viewed slide, completion tick or quiz score by itself is not sufficient. The website has exactly 11 modules, one-to-one with Drive modules 1-11. Each module is a teacher-adjustable two-week integration container anchored by the supplied 50-65 minute lesson; this must not be described as a formally authorised 22-week programme.

Each module contains exactly three TASK 11A named theory sections and exactly ten student-learning MCQs per section. This produces 33 sections and 330 MCQs overall. Each module should also contain:

- student name and class inherited from the course record;
- the relevant learning material and source/stimulus link;
- an answerable activity using the 2026 Drive worksheet as its coverage floor;
- a knowledge check grounded only in taught student learning;
- one scaffolded explanation, comparison or justification;
- visible autosave status;
- a card-level `Print / Save PDF` preview; and
- a link to the next stage and the twelve-card folio.

## Evidence completion rules

A stage is complete only when its meaningful required fields are present. Completion must not be triggered by a standalone checkbox.

Recommended minimum completion checks:

- required definitions and factual responses are non-empty;
- tables contain the required number of meaningful rows;
- a comparison includes both sides and at least one supported distinction;
- a justification includes a choice, evidence and reason;
- maps/images have an explanatory caption or annotation record;
- any source-linked statistic records the source/stimulus and the value used;
- challenge/reflection responses meet the displayed sentence or fact requirement; and
- required missing evidence is shown clearly in screen and print views.

Do not publish time-sensitive statistics, nutrition claims, industry figures, locations or animal-welfare claims without current verification. Use a current visible source/date or rewrite the activity as a source-reading task after verification.

## Plan-reading and practical evidence gate

### What is supported now

- The supplementary Stage 4 workbook contains a prompt to draw a plan of the school agriculture plot.
- The supplementary poultry booklet contains labelled equipment, production-system and biological diagrams.
- No dependence on either legacy source was confirmed in the current 2026 lessons, so neither can create a required task by itself.

### What is not supplied

No current, authoritative dimensioned agriculture-plot, poultry-shed or project production plan was found.

### Integration behaviour

Build only a gated plan-reading shell with the status `Teacher to confirm/provide current plan and task requirement`. It must not count towards completion or formal assessment until confirmed. When a current plan is supplied, students may record only information visible in that source:

1. plan title, source and revision/date if shown;
2. orientation, view, legend and scale if shown;
3. named areas, boundaries, equipment or components;
4. verified dimensions or quantities, each tied to its plan location;
5. movement/production flow and teacher-confirmed checkpoints;
6. one annotated plan extract or student sketch; and
7. one uncertainty or question requiring teacher confirmation.

Never infer a missing scale, distance, stocking capacity, shed layout, safety zone, materials list or construction sequence. If it is not shown or teacher-confirmed, display `Teacher to confirm`.

## Knowledge-check contract

- Across the course, validate exactly 33 named theory sections and exactly 330 MCQs: three sections per module and ten questions per section.
- Questions test taught student learning only.
- Never test outcome codes, programme labels, teacher/admin information, formal assessment metadata, file IDs/names, folder labels or web-route names.
- Every MCQ must map to the precise relevant student theory section and have one defensibly correct answer.
- Distractors should reflect plausible student misconceptions, not obscure wording tricks.
- First hint: direct the student to the precise relevant theory section.
- Secondary help remains separate. It may explain the concept but must not reveal the correct option.
- Feedback should explain why the concept is correct; it must not expose teacher-only answer documents.
- Do not use a quiz score as the only evidence. Keep the saved activity response and explanation.

## Autosave and recovery contract

- Use a versioned, course-specific root record and separate stage/card records.
- Save text, select, checkbox, ordering and completion data automatically after meaningful input changes.
- Show `Saving...`, `Saved locally` and a last-saved time; do not imply cloud submission.
- Restore the last valid record on reload and ignore/quarantine malformed data rather than destroying the valid record.
- Store authorised image blobs in IndexedDB with a thumbnail, caption, removal control and size limit. A file input value cannot be restored after reload.
- Provide a student-controlled JSON backup/restore containing text data and image references; if images are included, use a ZIP or equivalent complete export.
- Provide a clearly confirmed reset. Reset one stage/card separately from reset-all.
- Preserve student name/class with the evidence package while keeping assessment metadata independent.

Suggested implementation-neutral record shape:

```text
course -> student -> stages[1..11] -> cards[1..12] -> images -> completion -> updatedAt -> schemaVersion
```

## Print / Save PDF contract

The print view must include:

- course title, student name and class;
- generated/printed date labelled as such, not as a due date;
- all twelve cards in order;
- stage evidence, tables, captions and authorised images;
- visible `Missing evidence` notices;
- source/checkpoint notes and student reflection; and
- a final completion summary.

It must exclude navigation, buttons, hidden answer material, model answers, teacher-only answer files and unconfirmed formal metadata. Use a calm one-column layout with page-break control so headings do not separate from the first evidence block.
